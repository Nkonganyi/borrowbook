# Shop Credit Tracker

A Flutter application designed for local grocery stores to manage customer credit purchases and payment tracking.

---

## Features

- Authentication
- Customer Management
- Borrowed Items
- Payment Tracking
- Push Notifications
- Multi-user Support

---

## Technologies

Flutter

Supabase

Firebase Cloud Messaging

SQLite

---

## Installation

flutter pub get

flutter run
